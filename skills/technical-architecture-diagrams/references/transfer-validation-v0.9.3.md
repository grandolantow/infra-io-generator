# 跨模型迁移的验收规则

在继 Attention Residuals 后的 DeepSeek-V2、Hymba、Titans MAC 实际绘图中，采用三种不同结构，均经原生 draw.io Graph 导出、Inkscape SVG 导出、实际鼠标拖动及 16:9 浏览器检查。三题来源于已有参考风格，不能计为全新论文留出集；布局和端口仍由 Agent 针对任务编写。不要把此处的通过项扩大为完整模型覆盖或自动布局能力。

## 先定义机制专属的可见事实

- MoE：分别显示 token 到专家的数据、router 的选择/权重，以及权重到加权汇总的依赖。只有 router→专家和专家→sum，仍可能让读者误解权重来源。说明实际专家数量和示意数量的区别。
- MLA：区分低秩 Q 与联合 KV 压缩、content 与 decoupled RoPE；可见标出 cKV 与 KR 缓存，不能把 Q 或展开 K/V 标成缓存。显式计算视图须披露推理矩阵吸收没有展开。
- Hymba：两分支共享输入但并行处理；SSM 输出门控先于分支归一化；独立 norm 和 beta 缩放后按 Eq.3 相加再投影。不要因参考图的 Mean 标签而忽略原文公式。局部注意力说明要保留 meta prefix 对后续 token 可见的条件。
- Titans MAC：使用 M(t−1) 读取历史，attention 的 y(t) 更新到 M(t)，当前输出还会读取 M(t)。不能把所有状态边误当 next-step 回边，也不能只画 memory 更新而漏掉更新后状态到当前输出的依赖。区分固定 persistent tokens 和测试时可学习 neural memory。

## 几何检查需要覆盖文字和走线

正交且零矩形碰撞仍可能不好读。检查输入线是否穿区域标题，虚线边界是否穿注释，以及异源输入/输出线束是否仅隔几个像素。先移动标题、注释或入射端口，再增加折点。长距离状态边添加简短颜色说明，关键运算符不能缩得比普通文字还小。

本轮独立复核要求修复的两项为：MoE 的权重依赖缺失、Titans 段间说明被虚线穿过。修复后范围内 16 项可见事实通过，仍保留 DeepSeek-V2 专家输入/输出线束偏密为低严重度问题；不得改写成总体美观已获用户认可。

## 保持证据边界

分别记录：事实判断、可见 ID 存在检查、实际引擎路径、原生拖动、SVG text/image/foreignObject、HTML 禁用 JS 显示，以及实际页面缩放。SVG 渲染与对象保留不等于已测 Inkscape GUI 拖动；Graph runtime 不等于完整 draw.io EditorUi；16:9 页面不等于 PPTX 插入与编辑。

概念侧栏必须说明未展示的计算所有权。例如 KV 共享示意若只画两个层读取同一缓存，应注明是复用关系，未表达哪一层生产 K/V。保留首轮发现与修复后检查，不覆盖失败记录。

## 从不喜欢的原图风格重新设计

当用户要求把差评参考改成当前偏好时，优先选评分记录明确的论文；若原始图片未归档，说明只能匹配论文名称，不能把后来取得的 Fig.2/5 冒称当年的同一张图。以论文技术事实为依据，迁移信息组织和图元规则，不迁移原图坐标。

若任务同时要检验布局独立性，先基于正文、公式和代码生成并冻结初稿，保存源文件与哈希，再打开原图作对照；如实记录对照后修订。读过论文文字、图注以及模型既有知识，不等于严格盲测。对比信息组织、机制可追踪性及省略项，不预设新图一定比原图好看。

BLT 重设计中保留的检查：encoder→decoder 字节隐状态通路不能丢；两端 cross-attention 的 Q 与 K/V 角色必须反转；局部因果窗口可跨 patch，而 encoder cross-attn 只汇聚 patch 内字节；全局模型作用于 patch；decoder 先 cross-attn 再局部 Transformer。解码对齐应从固定代码检查，不能让同 patch 的未来字节泄漏。若画完整注意力算子，残差从未投影的输入状态开始；省略 Q/K/V、输出投影和 Norm 时要注明。

把“已完成 patch j → 预测 patch j+1 字节”的内部 patch 示意标明为 decoder alignment，避免被上方熵分组控制区吸收为辅助 LM 的计算。P0 的池化初始化要保持可见；局部机制展开过密时，按整页宽交付或拆成详情页，不能无限缩小字体。
