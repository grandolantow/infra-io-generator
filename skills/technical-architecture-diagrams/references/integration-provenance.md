# Dual-package interface and scope

The unified entry invokes two independent implementations:

- `technical-architecture-diagrams`: model backbones, modules and structural detail; existing draw.io/Inkscape/TikZ workflow.
- `technical-diagram-options`: technical mechanism options, semantic/geometry IR, public source citations and SVG/draw.io export.

The report route returns the actual package entry, selector, generator and schema paths. A natural-language routing hint is not a generated diagram. The Agent must construct verified task facts and diagram geometry before exporting.

Model default: paper-clear regardless of PPT/paper. Report default: huawei-plain for PPT, paper-vivid for paper or unspecified target. Explicit palettes/custom overrides take precedence. The report exporter uses colors in its IR; callers apply resolved palette roles to styles without changing facts or object identity.

Public source IDs and links support reference lookup, not a claim of source-image inspection or validation. Package tests cover executable contracts, not aesthetics, scientific correctness or generalization. Actual GUI rendering, editing and visual QA remain separate checks.

Install both complete sibling skill directories. Existing personal installations are not automatically overwritten.
