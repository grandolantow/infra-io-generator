# 生产与风格探索

默认 `paper-clear`（清彩论文），可选 `blue-neutral`（素雅灰蓝），不因用于PPT自动换色；指定模板可显式选择 `huawei-plain`。显式 palette 与颜色覆盖优先，详见 `palette-config.md`。保留用户确认的40式机制对照、31式主干展开、33式功能分块、34式直观机制。

可选择：
- mono：黑白印刷，依靠线型与运算区分；
- functional：按真实计算／状态／通信功能分区；
- editorial：暖白底、强调阅读顺序和结论；
- blueprint：浅蓝工程线稿，适合依赖与调度；
- dark：深底展示，用于明确要求的场景。

风格与布局为两个独立参数。上述配色预设不代表已经实现空间张量、手绘、等距或网格变种；这类几何变种必须具备真实语义并另验收。不得把六种配色预设宣传成六种不同机制表达。

参考集探索比例为25%，其分类为Agent选择，未经过用户人工评价。变种图的结果单独记录，不并入生产可用率。用户选择风格后，可调整颜色、密度与局部结构；每次调整仍须通过技术事实与实际显示检查。
