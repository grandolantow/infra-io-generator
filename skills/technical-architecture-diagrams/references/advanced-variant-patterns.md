# 结构与几何探索

三轮之外，已对同一个公开Attention Residuals底稿生成三张实际探索图：

1. 子层堆栈与算子展开：Standard固定单位权重，Full从历史输出读取；只展示3个抽象子层，并明确层数/层型是示意。
2. 张量几何：候选栈同时提供归一化keys和原始values；可学习query、深度softmax和Σ路径独立。
3. 单色公式：候选深度轴、权重计算与原始value旁路，保留公式与可追踪连接。

三张均为可编辑SVG与完整解码PNG，所有7个必要事实与范围文字可见；额外Chrome几何测量仍有7项文字bbox相交诊断，不能标所有几何通过。独立技术与用户偏好状态另记。

这些是一个公开机制的能力样例，未证明对所有模型的自动几何变种泛化。迁移时只能复用信息组织与小图元，不得复用本题的数学事实或硬编码层序列。几何长度不表达真实张量维度时明确标示示意。

五个额外视觉预设mono/functional/editorial/blueprint/dark已分别在Attention和PagedAttention生成，共10张。它们与3张几何探索合计13张额外样例，生产基线保持paper。风格预设与结构探索分开统计，不能宣传成13种独立风格。
