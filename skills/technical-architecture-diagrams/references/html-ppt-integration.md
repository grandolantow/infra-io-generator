# HTML PPT 接入边界

已读取 `LookAround0301/huawei-html-ppt` 当前README与component-reuse-and-review规范。宿主默认1280×720、自包含HTML，洞察页保留结论；已有Diagram组件与具名端口。当前没有向该仓库合入本Skill。

本Skill的架构图使用内容驱动的viewBox，不固定1600×900；已有1600×900样例只是历史实例，不是生产尺寸约束。模型主干优先竖向展开，可单独交付窄幅长图；右侧展开可有可无，不为适配16:9而填充或拉宽。

图形设计与幻灯片适配分两次验收：先检查原比例下的技术关系、阅读顺序、间距和字体；随后检查宿主内容区中的可读性。宿主按内容区等比缩放，保留标题和结论所需空间，不能压扁。竖图缩到整页后过小时，优先用左侧竖图配右侧讲解、分步展示或整图加局部放大；仍不可读时拆成多页。保留完整原比例源图，不以PPT排版版替换它。字体优先微软雅黑，缺失时使用可用中文回退。字体文件不随Skill分发。

输入为本题事实JSON，输出为SVG/布局JSON/QA；SVG可作为宿主section中的原生内联组件。需要继续用宿主Diagram时，逐节点转换并保留语义ID和边端口，不用整页PNG替代可编辑图。

组件适配不等于仓库集成：目前仅提供HTML嵌入入口，未验证宿主完整翻页／导出链路，也未提供统一PPTX转换。后续合入应匹配宿主最新版本，复用其acceptance、diagram_audit和visual-review记录。

## 配色接入

嵌入 PPT 时默认保留 `paper-clear`（清彩论文），不自动替换配色；可选 `blue-neutral`（素雅灰蓝），明确指定华为模板时选择 `huawei-plain`。用户指定 palette 时保留其选择；源文件、SVG 与 HTML 必须共用解析结果。颜色接入不代表已合入宿主仓库。
