# Validation scope

Run `python scripts/check_package.py` and `python -m unittest discover -s tests -v` from this package. The selector and diagram exporter can be exercised with the invented toy-mapping examples.

The checks validate source IDs, rule references, factual input requirements, semantic endpoints, stable native SVG/draw.io objects, escaping, and explicit unsupported inputs. They do not prove scientific accuracy, source-image quality, user preference or generalization. Actual render/GUI and visual inspection must be recorded separately for a deliverable.
