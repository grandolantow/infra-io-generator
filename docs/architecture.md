# 执行分层

1. 事实：固定论文/代码版本，列必要可见事实、运算、端点和省略项。
2. 结构：选择机制对照、主干展开、功能分区或状态机制；用公共锚点组织布局。
3. 母版：独立 draw.io 对象与稳定 ID，连线连接真实 source/target。
4. 渲染：官方 Graph 导入和导出；其职责是原生形状、连接、编辑和序列化，不自动提供论文审美。
5. 精修：Inkscape 曲线、转角和文字；复杂公式按需 TikZ。
6. 交付：原生源、SVG、PNG、自包含 HTML、事实和检查；PPT 是后续容器适配。

配色、画布与技术事实分别管理。默认「清彩论文」与可选「素雅灰蓝」是颜色变化，不能算结构候选。用户要求多结构时需在组织关系上产生真正差异。

仓库中的构建器是特定模型实例。MiniMax 原生源可独立修改重导；未提供替换论文 JSON 即自动生成架构图的能力。
